# Big Al's — A Man With A Van

A responsive, static website and matching vector brand kit for Big Al's. The site has no build step or third-party runtime dependencies; open `index.html` in a browser or serve this folder with any static web host.

## Before publishing

1. Add Big Al's real contact email to `businessEmail` near the top of `script.js`. The quote form validates its fields and opens the visitor's email app with a pre-filled request. It does not store or transmit the details.
2. Add a real phone number to `businessPhone` in `script.js`. The phone and email are then linked in the contact panel.
3. Confirm the service area, services, and wording match what Big Al can provide. No location, reviews, insurance, or credentials are claimed by this starter site.
4. The page uses Google Fonts when online and falls back to system sans-serif fonts.

## Brand and van files

- `assets/big-als-mark.svg` — compact logo mark used as the favicon and website brand icon.
- `assets/van-illustration.svg` — original, hand-drawn vector van used in the homepage hero.
- `assets/van-side-decal.svg` — scalable side-panel decal layout with a quote prompt.
- `assets/van-rear-decal.svg` — scalable rear-door decal layout with matching brand and services.

The decal SVGs are artwork layouts, not vehicle templates. Have the signwriter confirm dimensions, panel curves, door gaps, print colors, and bleed before production. SVG is vector artwork and can be scaled or imported into common design tools.
